# D1 영상 디자인 발주서

YouTube Shorts Maker의 **영상 안 화면 디자인**(D1) 발주 문서다.
편집 앱 UI(D2)는 범위가 다르고 마감도 한참 뒤이므로 별도 발주한다.

이 문서의 제약은 임의 가이드가 아니라 **렌더 엔진의 실제 한계**다.
제약을 벗어난 시안은 구현 비용이 수 배로 늘거나 구현할 수 없다.

---

## 1. 무엇을 만드는가

주제 하나를 입력하면 **세로형 상식 퀴즈 쇼츠**를 자동 생성하는 도구다.
영상 1편은 아래 장면이 순서대로 이어진다.

```
hook  →  [ question → countdown → answer ] x 문제 수  →  cta
```

- 문제 수는 3~5개, 총 길이는 약 38~58초 (4문제 기준 약 48초)
- 시청자는 소리 없이 보는 비중이 높다 — **텍스트만으로 내용이 전달되어야 한다**

---

## 2. 캔버스 규격

| 항목 | 값 |
| --- | --- |
| 해상도 | 1080 x 1920 (9:16) |
| 프레임레이트 | 30fps |
| 코덱 | H.264 / AAC |
| 좌표 기준 | 1080x1920 픽셀 절대값으로 표기 |
| 안전 영역 | 상하단 UI에 가리지 않는 여백 확보 — 여백값을 시안에 명시 |

---

## 3. 기술 제약 (가장 중요)

렌더링은 **FFmpeg `drawtext` 필터**로 수행한다. MoviePy를 쓰지 않는다.

### 구현 가능 — 추가 비용 없음

- 텍스트 렌더 (폰트, 크기, 색)
- 외곽선(border), 그림자(shadow), 반투명 박스 배경
- 절대 좌표 배치, 중앙 정렬
- 시간에 따른 표시/숨김
- **시간 표현식 기반 스케일 애니메이션** — 텍스트가 작게 시작해 커지는 연출 가능
- 단색 / 그라디언트 배경

### 구현 불가 또는 고비용 — 쓰기 전에 상의할 것

- 임의 벡터 도형 (원, 다각형, 아이콘)
- **원형 프로그레스 링 / 게이지**
- 그라디언트로 채운 텍스트
- 블러, 글로우, 마스크, 혼합 모드
- 텍스트 자간·행간 정밀 제어
- 파티클, 물리 기반 모션

위 항목이 필요하면 PNG 시퀀스를 미리 렌더해 얹는 별도 파이프라인이 필요하다.
**시안에 넣기 전에 먼저 알려달라.**

---

## 4. 폰트 요건

- **한국어 글리프 필수** (미지원 폰트는 렌더 시작 전에 오류로 걸러진다)
- **폰트 파일(.ttf/.otf)을 함께 납품**해야 한다 — 이름만으로는 사용할 수 없다
- **임베딩·재배포 가능한 라이선스여야 한다.** 데스크톱 앱에 동봉해 배포한다
  - Windows 동봉 폰트(맑은 고딕 등)는 재배포 불가라 사용할 수 없다
  - 라이선스 원문 링크를 함께 달아달라

---

## 5. 장면별 필요 시안

### 5.1 hook (도입)
시청자를 붙잡는 첫 화면. 짧은 문구 1~2줄.

### 5.2 question (질문)
질문 텍스트가 화면 중앙에 표시된다. 낭독 음성이 함께 나간다.
질문 길이는 가변이므로 **줄 수가 늘어나도 깨지지 않는 레이아웃**이어야 한다.
최대 몇 줄까지 허용할지 명시해달라.

### 5.3 countdown (생각할 시간)
3 → 2 → 1 표시. 낭독 없음. 문제마다 길이가 다를 수 있다.

> **숫자 강조 방식을 우선으로 제안해달라.**
> 원형 타이머는 3장의 "구현 불가" 항목에 해당해 파이프라인이 추가로 필요하다.
> 원형이 반드시 필요하다고 판단하면 대안으로 함께 제시해달라.
>
> 카운트다운 중 질문 텍스트를 계속 보여줄지도 함께 정해달라.

### 5.4 answer (정답 공개)
**영상에서 가장 중요한 순간이다.** 정답 텍스트가 등장하며 강조된다.

- 스케일(작게 → 크게) + 색상 강조까지는 추가 비용 없이 구현된다
- 시작 크기 / 목표 크기 / 색 전환 / 지속 시간을 수치로 명시해달라
- 해설 자막이 정답 **아래**에 붙는다. 강조 대상이 아니며 정답에 가려지면 안 된다
- 정답 텍스트가 길어도 커진 상태에서 화면 밖으로 넘치면 안 된다

### 5.5 cta (마무리)
구독·좋아요 유도 문구.

## 6. 함께 납품받을 것

| 산출물 | 수량 | 비고 |
| --- | --- | --- |
| 자막 스타일 프리셋 | **2개 이상** | 앱에서 사용자가 고르는 선택지가 된다. 1개만 받으면 해당 기능이 성립하지 않는다 |
| 배경 프리셋 | **2개 이상** | 단색 또는 그라디언트. 이미지 배경은 MVP 범위 밖 |
| 폰트 파일 | 1개 이상 | 4장 요건 |

자막 스타일 프리셋마다 아래 값을 수치로 명시해달라.

- 폰트 크기 / 색 (hex) / 외곽선 두께·색 / 그림자 유무
- 화면 내 위치 (1080x1920 기준 좌표 또는 정렬 + 여백)
- 최대 줄 수와 줄바꿈 기준

---

## 7. 납품 형식

- 장면별 시안 (Figma 또는 PNG)
- **모든 수치를 텍스트로 병기** — 좌표, 크기, hex 색상, 여백. 시안 이미지만으로는
  구현값을 특정할 수 없다
- 폰트 파일과 라이선스 원문 링크
- 애니메이션은 영상이 아니라 **시작/종료 상태 + 지속 시간(초)** 로 기술
