# 자막 스타일 프리셋 출처와 라이선스

`presets.json`의 색값은 **D1 영상 디자인 확정 스펙 6.1**에서 그대로 옮겼다
(`docs/design/d1-video-design-spec.md`). 제3자 파일이 아니라 이 프로젝트의 정의값이므로
**이 저장소의 라이선스를 따르고, 재배포와 앱 동봉에 조건이 없다.** 표기 문구도 필요하지 않다.

확정 스펙의 `P1`·`P2`·`P3`이 위 순서다. 배경 프리셋과 같은 이유로 번호를 이름으로 쓰지 않는다.

## 색 역할 6+1개

프리셋이 바꾸는 것은 **색과 그림자뿐이다.** y좌표·폰트 크기·줄 수는 3종이 공통이고 확정 스펙
5장이 소유한다 — 그래서 프리셋을 갈아도 레이아웃이 회귀하지 않는다 (6.1).

| 키 | 쓰이는 곳 |
| --- | --- |
| `body` | 질문, hook, cta line1 |
| `dimmed` | **정답 장면에서** 질문·index (죽이는 색) |
| `accent` | 확정된 정답, 카운트다운 숫자, cta punch, kicker, index |
| `answer_onset` | 정답이 등장하는 순간(0.15초)의 색. 0.35초에 `accent`로 바뀐다 (5.4) |
| `secondary` | 해설, hook meta, cta tail |
| `border` | 외곽선 |
| `answer_border` | 정답만 외곽선색이 다른 P3 때문에 있다 |

`answer_border`는 P1·P2에서도 `border`와 같은 값을 **명시한다.** "없으면 `border`를 쓴다"는
폴백을 두면 렌더러가 규칙을 하나 더 알아야 하고, 값이 비어 있는 것과 같게 지정한 것이
구분되지 않는다.

`shadow_alpha`가 `null`인 P2는 **그림자를 쓰지 않는 대신 정답 외곽선을 5→6으로** 올린다
(`answer_border_bonus: 1`). 요소별 그림자 오프셋(`+8`, `+6`, `+10`, `+12`)과 요소별 `borderw`는
확정 스펙 5장의 표이고 렌더러(#20~#22)가 소유한다 — 여기 있는 것은 프리셋 기준값과 그 차이뿐이다.

## 소비하는 쪽

- 이름 → 정의값 조회는 `shorts_maker.assets.caption_styles()` 하나다.
- `render.caption_style` 설정이 이 이름을 받고, 없는 이름이면 실행 시작 시점에 오류가 난다.
- 번인(#20~#22)이 색을 읽고, 앱의 자막 스타일 선택(#29)이 목록을 읽는다. **앱이 고른 스타일을
  프로젝트에 저장하는 필드는 아직 없다** — `project.json`의 편집 상태는 #26이 붙인다.
- `background`는 확정 스펙 6.3에서 ◎로 짝지어진 배경이다. **조합을 막는 값이 아니다** — 9조합
  전부 사용 가능하고, 앱이 스타일을 고를 때 기본 배경을 함께 제안하는 데 쓴다.
- 배경 대비 명도비는 `tests/test_visual_assets.py`가 커밋된 값에서 다시 계산한다. 측정값과
  하한은 확정 스펙 6.3에 있다.
